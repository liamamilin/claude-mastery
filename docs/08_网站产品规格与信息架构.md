# 08｜Claude Mastery Lab：出版级静态学习网站

## 品牌定位

- 中文站名：**驾驭 Claude**
- 英文标识：**Claude Mastery Lab**
- 标语：**不只会提问，更能掌控完成。**
- 产品承诺：真正教会读者如何从意图到成果，再从失败中重获控制。

## 关键体验（第一屏的30秒）

打开首页，访客立即看见：这是一套以 Claude Code Desktop 为主、包含八部分/32章、真实案例、纠偏训练与从零到交付的课程。两个主要入口：**开始入门** / **试一次纠偏练习**。视觉专业、信息清楚，内容优于装饰。

## 信息架构

```text
/                                 首页：价值、学习闭环、课程、案例、练习
/00-导读                          学习方式和环境
/chapters/01-理解...             真实已完成章节的阅读页
/chapters/22-停止...             招牌纠偏示范章
/labs/decision                    可交互决策训练（可嵌入章内）
/appendix/...                     术语、能力与FAQ（写好才链接）
```

网站**不展示不存在的章节阅读链接**。课程路线图可以显示未完成章节的标题并标注“规划中”，但导航只纳入真实有正文的页面。以后每新增一章再添加到真实导航。

## 首屏与主要模块

1. **Hero**：深色夜蓝背景、明亮文字与偏暖琥珀色细节；抽象工作闭环 SVG，与任一品牌官方视觉风格保持区别。
2. **学习闭环**：可理解的“意图 → 事实 → 路线 → 行动 → 证据 → 调整 → 交付”。点击步骤展示小解释，而非仅仅一张摆设图。
3. **课程路线图**：八部分32章作为规划展示；已完成的章节有真实链接，未完成清楚标记。
4. **案例卡**：A、D 的已有源码链接可打开，其余标“建设中”。
5. **快速训练**：无需后端的诊断情境，可点击、有解释、有重置、键盘可用。
6. **透明进度**：首页可见目前已发布章节数与已验证案例数，数据不得大于真实进度。

## 章节页

- 站内搜索、目录与子标题、上一篇下一篇。
- 代码复制功能与输入目标标签（提示框/终端）。
- 阅读舒适，行宽、行高、中文标点和代码块适配手机。
- 实用图表、实际截图、练习复位和答案反馈。
- 可选 localStorage 的阅读进度；隐私说明和清空选项，不伪装云同步。

## 可访问性和移动端

- 明确 focus 样式，键盘 Tab/Enter/Space 能完成核心操作。
- 主操作目标合适，不依赖 hover 展示关键知识。
- 颜色对比达一般网页可读标准；图解有替代文本。
- 360px 手机宽度不横向溢出正文，代码块自身水平滚动。
- 减少运动选项；动效仅辅助传达因果，不可影响阅读。

## 不能依赖运行时后端的功能

- 搜索：VitePress 构建时本地索引。
- 互动：Vue 客户端组件，数据本地模拟。
- 阅读进度：浏览器端本地状态（可选）。
- PDF/EPUB 下载：预先构建好的静态文件，只有文件真正存在才显示链接。
- Claude 的真实代码执行、终端与连接器：读者自己的 Desktop Code 环境，不通过 Pages 服务器执行。

## 视觉验收

- 首页首屏在手机和桌面均能明确表达核心价值；不空、不像默认文档模板。
- 课程卡、导航和 CTA 可实际点击；不存在的章节必须无法误点。
- 练习的每一种选择产生解释，错误路径也有学习价值。
- 实际阅读三页检查视觉一致性、代码换行/滚动、图片链接与深浅主题下可读性。
