# 09｜图解、真实截图、视觉系统与可选设计工具

## 视觉基调

“研究工作室 + 专业技术出版物”，不是炫光大屏，也不直接复制 Claude 官方品牌的界面或商标。主色建议：夜蓝/黑蓝 `#0B1220`，面板 `#101D2B`，温暖金铜 `#E8AD66`，正文 `#F4F1E9`，冷灰 `#9BB0C4`。这只是推荐初稿；以实际对比和可读性验证为准。

标题中文用系统字体栈优先，英文可用免费网页字体（需验证许可、缓存大小）；**不将商业字体文件随包分发**。

## 四类视觉资产，方法不能混淆

| 类型 | 内容 | 推荐制作方式 | 验证 |
|---|---|---|---|
| 解释关系 | 任务闭环、会话隔离、上下文流、验证流程 | SVG / Vue / CSS，可修改文字和线条 | 审阅每个箭头含义 |
| 解释步骤 | Claude Desktop Code UI、权限选择、diff、Browser pane | **实际 Claude Desktop 截图** + 注释图层 | 核对当前应用版本和图注 |
| 教学结果 | LinkShelf 页面、故障复现前后、浏览器测试 | 真正打开案例拍屏；可遮蔽隐私 | 与案例文件和版本一致 |
| 情绪和氛围 | 封面、八个章节篇章扉页 | 优先原创抽象 SVG/CSS；若可用 Claude Design 或已获授权生成图像，再做增强 | 不冒充真实软件 UI |

> Anthropic 官方帮助中心表示 Claude 不会直接像图片生成器一样生成照片/插画，但可以生成 HTML/SVG/互动视觉。Claude Design/Artifacts 属于可选设计能力，需在实际可用环境确认其输出能否融入源代码版本库。**不为了获得效果而强制购买图像 API。**

## 截图流程（只使用可信内容）

1. 在本机 Claude Desktop 打开对应案例，核对 app/Code 版本和布局。
2. 按章节操作到需要说明的状态，确认屏幕与实际文件或运行结果一致。
3. 用系统截图或可用 Browser/Computer use 取图（需要权限时先申请），原图保留在 `assets/screenshots/source/`，公开版本放入站点资源。
4. 遮蔽账户名、家目录、token、私有仓库与真实用户数据；不能泄露隐私。
5. 标注图号、作用、版本、获取日期、章节引用；不把生成的模拟截图伪装成真。

## SVG 图质量要求

- 文字是矢量可选文本；不把复杂概念压进一张太小的图。
- 桌面/手机均可阅读，过宽时提供分步解释或滚动。
- 颜色不能是唯一的状态区分方式；有文字说明及 alt。
- 让 Claude 为每张图解释“图中每个关系为什么成立”，杜绝概念错误。

## 动画纪律

动效服务学习：阶段推进、原因与结果高亮、差异对比。不要大面积视差、自动播放发光特效、无意义数字滚动；请尊重 `prefers-reduced-motion`。
