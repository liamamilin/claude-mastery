# Claude Mastery Lab — project instructions

This repository is the **source package** for the Chinese book and GitHub Pages learning site 《驾驭 Claude》, focused on **Claude Code in the Claude Desktop app's Code tab**.

## Success is working artifacts, not plans

- Write genuine, detailed, teachable Chinese chapters in `book/`; use `docs/01` as the 32-chapter editorial backlog.
- `book/*.md` and `book/chapters/*.md` are the **single source of truth**. The site and future PDF/EPUB are built from that content.
- Each chapter needs a clear outcome, actual reader steps, what to observe, what can go wrong, and a self-check. Every claim about UI/permissions/commands must match a tested environment or an official source with a check date.
- First milestone: finished intro + 3 real chapters, runnable Lab A, a polished mobile-ready site, and one functioning decision practice. Continue sequentially without asking permission after every batch.
- Be Desktop-first: distinguish Code from Chat/Cowork, local/cloud/SSH, Desktop-specific controls from CLI commands. Never assert that unavailable or plan-gated features are universal.
- Verify changes using the Desktop Browser pane and terminal when available; use actual screenshots, not generated fake UI.
- Use editorial SVG diagrams and CSS; use authorized image-generation or Claude Design only when available and useful. No purchases or public deployment without explicit approval.
- Deploy target: **static GitHub Pages only**. Never introduce mandatory runtime backend, database, user accounts or server-side Claude Code execution.
- Preserve a tiny `STATUS.md` with completed files, commands executed, test results, blockers and next action. If stuck, test assumptions, change course and produce usable partial work. Avoid elaborate workflow gates.

Read `START_HERE.md` and `docs/14_直接交给Claude的启动指令.md` for the current assignment. Prefer source evidence in `docs/05_官方资料与版本核查.md`.
