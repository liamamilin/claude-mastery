# Teach one thing all the way through

Read `docs/07_章节正文写作标准.md` and the corresponding chapter contract in `docs/02_完整目录与逐章任务.md`.

1. Identify the reader's exact starting condition and a testable end condition.
2. Check Desktop-specific claims in `docs/05_官方资料与版本核查.md` against current official sources and, where possible, the active Desktop Code UI. Do not invent UI controls or outputs.
3. Write real Chinese teaching prose with a usable example, prompting context, observation, troubleshooting, and transfer exercise.
4. For code samples, run them or mark them as illustrative; attach actual case source when available.
5. Add precise SVG or actual screenshot only where it teaches a relation/step; never use invented screenshots as evidence.
6. Update actual navigation and `STATUS.md`. Deliver source files, not another abstract plan.
