# Lab C｜Web Preview Lab：让桌面版真正验证网页

一个纯静态的“学习进度看板”：卡片网格、状态筛选、空数据与加载失败状态。**无依赖、无 npm。**

## 运行

```sh
python3 -m http.server 48127 --bind 127.0.0.1
```

打开 `http://localhost:48127/`。`?empty=1` 看空数据，`?error=1` 看加载失败。

## 刻意保留的缺陷（给教师）

`styles.css` 把网格写成固定的 `repeat(3, 320px)`：**桌面宽屏正常，窄屏出现横向滚动**。第 17 章让读者用 Browser 窗格换尺寸发现它。`solution/` 是修复参考（`auto-fill` + `minmax`，并让筛选按钮可换行），请勿提前打开。

## 验收

1. 筛选：全部 6 项；进行中 2；已完成 1；未开始 3。
2. `?empty=1`：显示“暂无数据。”。
3. `?error=1`：显示“数据加载失败：模拟的加载失败”。
4. 375px 宽度：**没有横向滚动**（起始版本应当失败，solution 应当通过）。
