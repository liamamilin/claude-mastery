# Lab A｜LinkShelf：第一个真正能用的收藏工具

这是一个**可直接阅读源码**的三文件静态项目，不用账号、不接外部 API、不安装 npm。适合第一至四章训练“任务描述→修改文件→亲自验证”。

## 打开

打开 `index.html`，添加带 `https://` 的有效 URL。若某浏览器对 `file://` 下的 localStorage 有限制，可在当前目录运行：

```sh
python3 -m http.server 48123
```

然后用浏览器访问 `http://localhost:48123/`。**同一次验收始终使用相同的 URL 来源地址**，因为本地存储与网站来源绑定。

## 读者要验证的动作

1. 新增收藏后，页面出现此收藏。
2. 刷新后，收藏仍存在。
3. 删除收藏后刷新，收藏不再出现。
4. 输入不合法的 URL 或空标题，显示可理解的错误信息。

## 说明

应用的本地存储只在同一浏览器同一来源地址内可见；清除浏览器数据会删除记录。这不是云端同步工具。请不要用真实的个人收藏资料做第一轮练习。
