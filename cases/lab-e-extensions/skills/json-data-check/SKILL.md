# JSON 数据文件检查

目标：在改任何代码之前，先确认数据文件本身是否合法，避免把“数据坏了”误判成“代码坏了”。

## 步骤

1. 确定要检查的文件：优先使用用户给的路径 `$ARGUMENTS`；没有给出则在当前项目的 `data/` 目录里找 `.json` 文件。
2. 运行检查脚本（只读，不修改文件）：

   ```sh
   node ${CLAUDE_SKILL_DIR}/scripts/check_json.mjs <文件路径>
   ```

3. 向用户汇报：
   - 文件是否合法；
   - 不合法时，脚本给出的错误信息，以及它在能定位时给出的“提示：第 N 行第 M 列”（目前只会识别尾逗号；其他错误只有解析器的原始信息）；
   - 区分“事实”（脚本输出）和“推测”（你认为的原因）。
4. **不要自动修复数据文件。** 先报告，让用户决定。
