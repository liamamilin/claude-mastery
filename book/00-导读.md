# 导读｜你真正要学会的，是把 Claude 带向结果

欢迎来到《驾驭 Claude》。本书的主角不是某个版本的按钮，也不是一套万能提示词。主角是**你如何与 Claude 协作完成真实任务**。

Claude Code 能读项目文件、修改代码、运行命令；Claude Desktop 的 **Code** 标签页则让你可以在图形界面中观察工作过程：任务、文件、终端、变更、运行结果都能看到。然而，拥有这些工具不等于能驾驭它们。

想象你提出：“帮我做一个收藏链接的工具。”Claude 很快完成一个页面，说“好了”。你点击保存，却发现刷新后数据没了。接下来是继续写“请修好”还是去寻找保存数据的事实？这正是整本书要训练的能力。

## 学习路线

课程规划分为八个部分、32章：从理解桌面工作台出发，经过明确目标、管理上下文、控制执行、验收交付、纠偏恢复、扩展工具、复杂项目，最终完成一份陌生项目的毕业任务。

## 你的学习习惯

1. **先动手，后记忆**：每次遇到新概念，至少在实际项目中观察一次。
2. **看文件，不只看回复**：Claude 说它做完，不代表文件已经符合需求。
3. **接受合理变化**：每个人得到的具体代码可能不同，检查的是功能行为和证据。
4. **做出取舍**：有时最好的行动是请求 Claude 暂停，先把一个关键假设查清。
5. **保持可接续**：重要的目标、结果、未完成部分放进项目文件，而不是寄希望于长对话永远不丢上下文。

## 开始前准备

- Claude Desktop 应用并登录可以使用 Claude Code 的账户。具体计划、版本和安装步骤参照 [官方 Desktop 快速入门](https://code.claude.com/docs/en/desktop-quickstart)。
- 一个用于练习的空目录。请不要在真实、未备份的重要项目上执行首次改动练习。
- 能打开 HTML 的浏览器。进阶案例需要 Git 和 Node.js；书中在第一次用到时解释如何安装与检查。

## 怎样判断自己学会了？

学会不是能背出 `CLAUDE.md` 或 Worktree 定义，而是能回答：我在什么环境工作？Claude 实际读写了哪些文件？有什么证据证明完成？如果继续失败，最小的下一步调查是什么？
