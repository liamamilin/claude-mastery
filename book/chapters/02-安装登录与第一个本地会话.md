# 第 02 章｜安装、登录与启动第一个本地会话

> 本章终点：你在一个空练习目录里建立了 **Local（本地）** 会话，并且能说出这个会话的四个设置——环境、文件夹、权限模式、模型——各自管什么。你还会学会一个习惯：**先核对当前版本，再相信任何教程里的菜单名。**

## 1. 为什么先花一章在“启动”上

很多人的第一次失败，不是 Claude 写错了代码，而是会话从一开始就开在了错误的位置：选成了云端环境，却以为在改本机文件；或者打开了一个存放着重要资料的目录，却没意识到 Claude 可以读写其中的内容。

启动一个会话时，你其实做了四个选择。它们都在输入框**下方的一行控件**里，从左到右依次是：

| 位置（从左到右） | 控件 | 决定什么 |
|---|---|---|
| 1 | 环境选择器 | Claude 在哪里运行：Local、Cloud、SSH，Windows 上还有 WSL |
| 2 | 项目文件夹 | Claude 的工作目录是哪一个 |
| 3 | 权限模式 | 改文件、执行命令前，需不需要你批准 |
| 4 | 模型选择器 | 由哪个模型来完成任务 |

官方参考把这一排控件列为开启会话的核心步骤。这一章我们逐个认识它们，并做出一组**最保守、最适合学习**的选择。

## 2. 准备：账号、计划与系统

### 你需要什么

- **一个可使用 Claude Code 的付费计划。** 官方快速入门写明 Claude Code 需要 Pro、Max、Team 或 Enterprise 订阅。如果你点击 Code 后看到升级提示，说明账号计划还不满足。
- **桌面应用本身。** 官方提供 macOS（Intel 与 Apple Silicon 通用安装包）和 Windows（x64；ARM64 有单独安装包）。Linux 版本为 **beta**，通过 apt 或 `.deb` 安装，面向 Ubuntu 与 Debian。
- **不需要**为使用 Code 标签页单独安装 Node.js 或命令行工具——官方说明桌面应用已内置 Claude Code。本书后面用到 Node 时（例如运行网站）会另行说明。

> **关于“内置”与“独立 CLI”**：桌面应用里的 Claude Code 与你另外安装的 `claude` 命令行程序不一定是同一个版本，会话列表也不自动互通。本书以桌面版为主，只在特别标注 **[CLI 可选]** 的地方才提到命令行。

### 安装并登录

1. **[浏览器]** 打开官方桌面入门页 <https://code.claude.com/docs/en/desktop-quickstart>，按你的系统下载安装包。
2. **[系统]** 运行安装程序。macOS 从“应用程序”打开 Claude；Windows 从开始菜单打开。
3. **[Claude Desktop]** 用你的 Anthropic 账号登录。

若出现“请在浏览器完成登录”的提示，完成登录后**重启应用**。

## 3. 打开 Code 标签页

登录后，侧边栏顶部有几个标签：**Chat**、**Cowork**、**Code**。点击 **Code**。

> 如果标签只显示图标，没有文字，把鼠标悬停在图标上就会出现名称。

点击后可能遇到三种情况（均来自官方入门页的排错说明）：

- **提示升级**：你需要先订阅付费计划。
- **提示在线登录**：在浏览器完成登录，然后重启应用。
- **403 错误**：参考官方“认证问题”排查段落。

这三种都不是你操作错了，而是账号或登录状态的问题。**不要因此就改用 Chat 来“假装”做 Code 的练习**——在 Chat 里写出来的代码不会自动出现在你的文件夹里（第 1 章已经解释过这个区别）。

## 4. 创建练习目录

**[系统文件管理器]** 新建一个空文件夹。如果你在第 1 章已经建了 `my-claude-lab`，可以继续使用它；否则现在新建一个，比如放在“文稿”里。

为什么要新建而不是用现有项目？因为这是你**第一次**让一个能写文件的程序在你的电脑上工作。让它先在一个丢了也不心疼的目录里练习，是最便宜的保险。

## 5. 做出四个选择

**[Desktop Code]** 在 Code 标签页新建会话（点击侧边栏的 **+ New**，macOS 快捷键 `Cmd+N`，Windows 为 `Ctrl+N`）。然后沿着输入框下方那一排控件，从左到右设置。

### 5.1 环境：选 Local

点击第一个控件，在 **Local** 分组里选择最上面的一项。

- **Local**：在你自己的电脑上运行，可以直接访问本地文件。这是本书的默认路径。
- **Cloud**：在 Anthropic 管理的基础设施上运行，关闭应用后会话还会继续；它面向的是代码仓库而不是你的本地文件夹。
- **SSH**：连接到你自己的远程机器。需要事先添加连接。
- **WSL**（仅 Windows）：在 WSL 2 发行版里运行。

现阶段只用 Local。Cloud 与 SSH 在第 30 章专门讲，它们并不是“更高级的 Local”，而是**文件所在位置不同**——这一点会改变很多事情。

### 5.2 项目文件夹：选 Open folder…

点击环境选择器旁边的项目文件夹控件，选择 **Open folder…**，然后选中刚才的练习目录。

确认方法：控件上显示的文件夹名，应该是你刚才创建的目录。如果显示的是别的名字，**现在就改**，不要等到 Claude 开始写文件。

### 5.3 权限模式：学习阶段用 Manual

第三个控件是权限模式。当前桌面版提供这些选项：

| 界面名称 | 行为 |
|---|---|
| **Manual** | 改文件或运行命令前都先询问，你逐个接受或拒绝 |
| **Accept edits** | 自动接受文件编辑和常见的文件系统命令（如 `mkdir`、`touch`、`mv`）；其他终端命令仍会询问 |
| **Plan** | 只探索并提出计划，不修改源代码 |
| **Auto** | 不做常规询问，由后台分类器在动作执行前检查并拦截风险操作 |
| **Bypass permissions** | 几乎不再询问，只保留少数受保护动作；官方建议只在沙箱容器或虚拟机里使用 |

几个容易误解的点：

- **老版本的名字不同。** 官方注明早期标签曾叫 “Ask permissions”“Auto accept edits”“Plan mode”。如果你的界面是旧布局，名字对不上，不代表它们不存在。
- **有的选项可能看不到。** Auto 对模型有要求；Bypass permissions 在 Pro/Max 需要先在设置里打开开关，在 Team/Enterprise 由组织策略控制。云端会话也不提供 Bypass。**看不到某个选项时，先别怀疑自己，这是计划或组织策略的正常差异。**
- 除 Plan 外，你选过的模式会按文件夹被记住。

**本书前几章请选 Manual。** 理由很具体：Manual 下每次修改都会先给你看 diff，你能亲眼看到“Claude 要做什么”和“最终做了什么”之间的距离。这种感觉比任何文字解释都有效。等你熟悉了，第 13 章会专门讨论怎样为不同任务选择自主程度。

### 5.4 模型：先用默认的

第四个控件是模型选择器，位于这一排的靠右位置。学习阶段保持默认即可。可用模型随计划和时间变化，官方模型页有对比：<https://code.claude.com/docs/en/model-config.md#available-models>。你随时可以在会话中途切换。

## 6. 核对你的版本

教程里的按钮名会过期，所以养成一个习惯：记下你当前的版本。

**[Desktop Code]** 在应用的 About / 关于 页面（不同系统菜单位置不同）查看版本号，把它连同日期记在练习目录的一个笔记里。官方文档指出，窗格拖拽布局需要 Claude Desktop **v1.2581.0 或更高版本**；如果你的版本更低，布局可能与本书描述的“旧布局”相同。

如果输入框下方**没有**环境选择器，说明你用的是更早的布局。官方参考里有“检查你用的是哪个布局”一节，按它的说明对照即可。

## 7. 验证：会话真的开在正确的地方吗？

不要以为选完就一定对。发送下面这段，让 Claude 自己报告：

**发送到 [Desktop Code] 的提示框（只读，不改文件）：**

> 请告诉我：你当前的工作目录的完整路径是什么？目录里有哪些文件？这是一个本地会话还是云端会话？如果你无法确定，请说明你是怎么判断的。请不要创建或修改任何文件。

### 你应该看到

- Claude 给出的路径，与你在文件管理器中的练习目录一致。
- 新建的空目录显示为空（或只有你自己放进去的文件）。
- 在 Manual 模式下，读取文件列表这类只读操作可能不需要批准，也可能弹出询问——两种都正常，取决于具体动作。

**这就是本章的验收：路径对、目录对、没有被修改的文件。**

## 8. 常见失败

**失败 A：路径是另一个我不认识的目录。**
说明项目文件夹没有选对，或者你打开了一个旧会话。新建会话，重新选择文件夹；不要在这个会话里继续。

**失败 B：Claude 说自己看不到任何本地文件。**
先检查第一个控件是不是误选了 Cloud。云端会话面向仓库，不是你的本地文件夹。

**失败 C：没有 Local 选项，或者环境选择器是灰色的。**
这可能由组织策略造成。记下你看到的选项，对照官方参考；如果是企业账号，询问管理员。不要自己想办法绕过限制。

## 9. 独立练习

1. 关掉这个会话，再新建一个，这次**不要看本章**，自己设置好四个选项并用只读提示验证路径。
2. 把权限模式切到 **Plan**，请 Claude 说明“如果要在这个目录里做一个收藏链接的页面，它会怎么做”。比较 Plan 与 Manual 的区别：哪一种会弹出 diff？为什么？

## 10. 掌握检查

1. 输入框下方那一排控件，从左到右各是什么？
2. 你选的是 Local，却发现 Claude 看不到你新建的文件。可能的原因有哪些？先查哪一个？
3. 为什么学习阶段推荐 Manual，而不是 Auto？
