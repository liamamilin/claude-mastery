# 第 31 章｜浏览器工具、Computer use、Design 与 Artifacts

> 本章终点：你分得清五种“能看见、能操作界面”的能力——**Desktop 内置 Browser 窗格、Claude in Chrome、Computer use、Claude Design、Artifacts**——知道各自能做什么、不能做什么，并能为一个具体验证任务选出**最小够用**的那一种。

> **本章是条件性章节。** 其中部分能力取决于计划、操作系统与组织策略，且多数处于预览或迭代中。作者**没有**逐一实测它们；本章依据官方文档（2026-10-26），并把“官方说了”与“我验证了”分开写。

## 1. 先问：我要的是“看”，还是“操作”，还是“做出东西”

| 你想要 | 候选能力 |
|---|---|
| 看本地网页的运行效果，让 Claude 点一点、读控制台 | Desktop **Browser 窗格**（第 17 章） |
| 在你**真实的 Chrome**（含登录态）里做事 | **Claude in Chrome**（独立扩展） |
| 操作**原生桌面应用**（没有命令行和 API 的那种） | **Computer use** |
| 产出一个视觉设计、原型或演示稿 | **Claude Design** |
| 产出一个可分享的网页或小工具 | **Artifacts** |

权限和风险依次递增：看本地页面的风险最小；接管你真实的浏览器或整个桌面的风险最大。**用最小够用的那一个。**

## 2. Desktop Browser 窗格（已在第 17 章实操）

- 在 Desktop 里的 Browser 窗格由应用提供，与你的 Chrome 隔离；预览本地开发服务器、点击、读控制台、截图都在这里；
- 官方说明它在 **SSH 会话里不可用**（第 30 章）；
- 本书所有案例的验证都用这一种，因为它的权限最窄：只在本地页面里动。

## 3. Claude in Chrome

- 官方把它描述为**独立的浏览器扩展**，让 Claude 在你的 Chrome 里操作（含你已登录的网站）；
- 正因为共用你的登录态，风险高：**它能看到、点击你已登录账号里的东西**；
- 提示注入（第 26 章）在这里最危险：网页里的一句话可能试图让 Claude 去做不该做的事；
- 建议：只在你确实需要登录态时使用；任务期间不要登录与任务无关的敏感站点；对发送、购买、删除这类**不可逆**的操作，坚持由你亲自点。

## 4. Computer use

官方文档（2026-10-26）要点：

- 是 **macOS / Windows 上的研究预览**，面向 **Pro / Max**（**不含 Team / Enterprise**）；
- 在 Desktop 里需要在设置的 **This computer > System** 下开启；
- 让 Claude 看屏幕、移动鼠标、点击、输入——用于**没有 API 或命令行的原生应用**。

使用原则：

1. **先问有没有更窄的办法。** 能用命令行、文件或 Browser 窗格完成的，不要动用整个桌面；
2. **在隔离环境里做。** 可能的话，用只开着任务相关窗口的状态；
3. **别在屏幕上放着与任务无关的敏感内容**（密码管理器、私人聊天）；
4. **截图也是数据**：屏幕上的文字一样可能含提示注入；
5. 作者**没有**启用或实测它。

## 5. Claude Design

官方文档（2026-10-26）要点：

- 先澄清一点：**Claude 不像图像生成器那样生成照片或插画**。它产出的是 **HTML、SVG、图表**这类可编辑的东西——这也是本书的图解全部是 SVG 的原因；
- Claude Design 是一类“**艺术品模板**”，所有计划可用；Claude Code 里有 `/design` 与 `/design-sync`；
- 可以导出为 zip、PDF、PPTX、HTML，并可**交接给 Claude Code** 继续实现；
- 官方公告：独立的 claude.ai/design 入口将在 **2026-12-14** 关闭；Enterprise 默认开启时间为 **2026-10-15**。**这类产品形态变化快，使用前以官方页面为准。**

适合：原型、版式、演示稿、可视化草图。不适合：需要照片级图像、需要精确品牌资产的情形（那需要别的工具或设计师）。

## 6. Artifacts

- Artifact 是 Claude 产出的**可单独打开和分享的网页或小工具**；
- 适合：把一份报告、一个计算器、一个看板做成别人点开就能用的页面；
- 注意：发布即**分享**。内容是否含敏感信息、是否适合让别人看到，是你的责任（第 20 章）。

## 8. 失败分支

- **工具看不到你的页面**：本地服务没起，或页面需要登录（Browser 窗格是隔离的，不带你的登录态）；
- **Claude 在页面里被“劝说”做别的事**：停下，原文报告给你（第 26 章）；
- **Design 产出与品牌不符**：给它真实素材（色值、字体、已有页面），而不是形容词；
- **不确定某能力是否对你开放**：看设置与官方说明，不要猜。
