# 附录 C｜常见报错诊断路径

先用第 21 章的分层：**输入 → 环境 → 数据 → 逻辑 → 工具 → 权限 → 网络 → 理解**。每条给“先看什么”，不给魔法命令。

| 症状 | 先看什么 | 章节 |
|---|---|---|
| 登录/认证失败 | 账号与计划是否匹配；是否在正确的应用/环境；重新登录 | 2、23 |
| 权限被拒 / 反复弹确认 | 当前权限模式；该操作是否本该由你确认 | 13 |
| `command not found` | 终端里 `which 命令`；PATH；Desktop 与你的终端环境可能不同 | 23 |
| `npm` 报错 | Node 版本（本书 22）；是否用 `npm ci`；锁文件是否在 | 20 |
| 端口被占用 | `lsof -i :端口`；换端口并同步 `launch.json` | 17 |
| 页面空白 | 控制台报错；网络请求是否 404；ES 模块是否被 `file://` 打开 | 17 |
| 改了代码页面没变 | 是否改到了运行的那份；缓存；服务是否重启 | 22 |
| 数据刷新就丢 | 存储是否真的写入；检查 `localStorage` | Lab D |
| Pages 子路径 404 | `base` 是否是 `/仓库名/`；原始路径是否用 `withBase()` | 20 |
| Git 冲突 | `git status` 看冲突文件；不确定就 `git merge --abort` | 15、16 |
| Hook 不触发 | 位置、JSON、matcher、可执行权限、新会话 | 27 |
| 子代理不被调用 | `description`、目录、字段拼写 | 28 |
| 云端看不到我的改动 | 是否推送了分支 | 30 |

**通用第一步：** 把原始报错原文复制下来，不要转述。第二步：复现一次。第三步：才问 Claude，并附上原文。
