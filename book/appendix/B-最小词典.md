# 附录 B｜前置知识最小词典

只解释本书用到的意思。

| 词 | 一句话 |
|---|---|
| 目录 / 文件夹 | 放文件的地方；Claude 的会话绑定一个工作目录 |
| 终端 | 输入命令的窗口；Desktop 里是 Terminal 窗格 |
| Node / npm | 运行 JavaScript 的环境 / 它的包管理器。本书网站用 Node 22 |
| `npm ci` | 严格按锁文件安装依赖，适合构建和持续集成 |
| Git | 版本管理工具，记录每次改动 |
| commit | 一个你可以回去的存档点 |
| diff | 两个版本之间的差异 |
| 分支 | 一条独立的改动线 |
| 工作树（worktree） | 同一仓库的另一个工作目录，各自一条分支，互不干扰 |
| 合并冲突 | 两处改动改了同一位置，需要人决定 |
| localhost | 你自己这台电脑；`http://localhost:端口` 是本机上的服务 |
| 端口 | 一台机器上的服务编号。冲突时换一个 |
| 构建 | 把源文件变成可发布的静态文件 |
| 部署 | 把构建结果放到别人能访问的地方 |
| GitHub Pages | GitHub 提供的静态网站托管 |
| base（子路径） | 站点不在域名根而在 `/仓库名/` 下时的前缀 |
| CLAUDE.md | 项目的长期说明，会被载入上下文；是建议，不是强制 |
| Skill | 带说明的可复用方法（`SKILL.md`） |
| Hook | 在特定时刻**确定地**执行的命令 |
| Subagent | 独立上下文里运行的助手，只回传总结 |
| MCP | 连接外部工具的开放标准 |
| 提示注入 | 外部内容里夹带对 Claude 的指令；当数据，不当命令 |
